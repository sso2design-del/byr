# Byr 홈페이지 콘텐츠 가이드 (Claude Code 구현용)

원칙: AI 용어 남발 금지, 기능 설명보다 업무 결과 중심, 짧고 명확한 문장.

---

## 1) 핵심 메시지 (한 줄)
우리 팀이 매일 반복하는 일을, 안전하게 맡기고 빠르게 끝낸다.

보조 메시지:
- 복잡한 업무도 단계별로 자동 실행
- 중요한 결정은 사람 승인으로 통제
- 결과는 기록으로 남고 언제든 추적 가능

## 2) 권장 섹션 순서 (히어로 제외)
1. 문제 공감 + 가치 제안

4. 팀 운영/협업 방식
5. 승인·보안·감사 이력
6. 도입 신뢰 요소(도입 조직/산업/성과)

## 3) 섹션별 콘텐츠 초안

### 3-1. 문제 공감 + 가치 제안
제목:
- 매일 반복되는 업무, 이제 맡기고 확인만 하세요

본문:
- 문서 정리, 보고서 초안, 승인 요청, 상태 확인까지.
- 팀이 자주 하는 일을 표준화해 누락 없이 처리합니다.

CTA:
- 무료로 시작하기
- 도입 상담 받기

### 3-2. 핵심 사용 시나리오 (칩/카드 형태)
레이블 예시:
- 세금계산서 점검
- 월간 운영 리포트 초안
- 회의록 요약 및 후속 작업 정리
- 승인 대기 건 일괄 확인
- 사내 문서 근거 검색
- 고객 문의 답변 초안

설명 문장:
- 클릭 한 번으로 자주 하는 업무를 저장하고, 필요할 때 바로 실행합니다.

### 3-3. 동작 방식 (4~5단계)
단계:
1) 요청 접수
2) 자료 수집
3) 초안 생성
4) 승인 요청
5) 결과 전달

설명:
- 진행 상태가 단계별로 보여서, 지금 어디까지 처리됐는지 바로 알 수 있습니다.

### 3-4. 팀 운영/협업
소제목 A: 내 에이전트 운영
- 필요한 에이전트를 검색/필터로 빠르게 찾기
- 즐겨찾기와 스케줄로 반복 업무 고정

소제목 B: 팀 에이전트 협업
- 역할별 작업 순서 구성
- 재실행/반려/승인 흐름을 팀 단위로 관리

### 3-5. 승인·보안·감사 이력
제목:
- 중요한 작업은 사람이 최종 승인합니다

포인트:
- 승인 전 자동 대기
- 권한 분리(설정 권한/실행 권한)
- 실행·승인·반려 이력 보존

### 3-6. 도입 신뢰 요소
제목:
- 다양한 산업의 팀이 Byr로 업무를 운영합니다

콘텐츠 형식:
- 산업군 태그/로고(제조, 금융, 유통, 헬스케어, IT, 공공)
- 운영 지표(예: 운영 중 에이전트 수, 템플릿 수, 연동 도구 수)

### 3-7. 요금/도입 방식
카드 A: 클라우드
- 가입 즉시 사용
- 파일럿/소규모 팀 적합

카드 B: 프라이빗
- 보안·권한 정책 맞춤
- 민감 데이터 중심 조직 적합

### 3-8. FAQ (권장 4개)
1) 개발을 몰라도 쓸 수 있나요?
- 템플릿 선택 후 옵션만 설정하면 됩니다.

2) 메신저에서 무엇을 할 수 있나요?
- 승인, 반려, 재실행, 상태 확인을 처리할 수 있습니다.

3) 답변 근거를 확인할 수 있나요?
- 관련 문서/문맥과 함께 결과를 제공합니다.

4) 중요한 작업도 자동 실행되나요?
- 아니요. 승인 게이트를 통과한 작업만 최종 실행됩니다.

### 3-9. 최종 CTA
제목:
- 우리 팀 업무, 오늘부터 줄여보세요

본문:
- 가장 반복되는 업무 하나만 먼저 자동화해도, 팀의 시간이 달라집니다.

버튼:
- Byr 시작하기
- 요금 보기
