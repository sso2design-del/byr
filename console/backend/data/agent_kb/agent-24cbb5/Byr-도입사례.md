# Byr 도입 사례

아래 사례는 데모용 가상 예시다(실제 고객 아님). 제안서 초안의 근거 인용 시연을 위해 구성했다.

## 사례 1 — 중견 제조사 재무팀 (약 40명 규모)
- 문제: 분기 부가세 대사에 담당자 2명이 3일씩 소요, 수기 대사 과정에서 누락·중복이 반복됐다.
- 도입: 재무 대사 에이전트를 매입·매출 원장에 연결, 골든샘플(직전 분기 확정치) 대비 자가검증.
- 효과: 대사 소요가 3일 → 반나절로 단축, 이상 항목을 사람 승인 전 자동 표시. 마감 리스크 감소.

## 사례 2 — SaaS 스타트업 CS팀 (약 12명 규모)
- 문제: 반복 문의(요금·환불·연동)가 전체의 60%를 차지해 응대가 밀렸다.
- 도입: CS 응대 에이전트를 FAQ·정책 문서에 연결, Slack 고객 채널에 배치. 답변 초안을 상담사가 승인 후 발송.
- 효과: 1차 응답 시간 평균 4시간 → 20분, 상담사는 예외 케이스에 집중.

## 사례 3 — 금융 계열사 준법·감사팀 (설치형)
- 문제: 내부통제 점검·이상거래 모니터링 리포트를 매주 수기로 작성.
- 도입: 설치형(프라이빗 클라우드)로 배치, 테넌트 격리 + 작업 기록부로 전 과정 감사 추적.
- 효과: 리포트 작성 자동화 + 규제 대응에 필요한 감사 증적 확보. 데이터는 외부로 나가지 않음.

## 공통 패턴
도입 효과가 큰 조직의 공통점: (1) 반복 문서·데이터 업무 비중이 높고, (2) AI 결과를 사람이 검증·승인하는 절차가 이미 필요하며, (3) 근거·감사 추적이 중요하다. Byr의 "사내 근거 + 사람 승인 + 감사 기록"이 이 세 지점에 정확히 대응한다.
