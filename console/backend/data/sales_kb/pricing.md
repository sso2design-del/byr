# Byr 요금제 (월 정액)

과금 축은 사용량이 아니라 정액이다. 에이전트 생성·실행 무제한, 전 스킬 개방은 전 티어 공통이며, 티어 차등은 설정·거버넌스 깊이로 둔다. (가격은 제안·미확정.)

## 스타터 — 월 ₩39,000 (연납 시 월 ₩31,000)
- 대상: 개인~소규모(1~10명)
- 에이전트 무제한 생성, 정액 무제한 실행(토큰 걱정 없음)
- 전 스킬 개방, 내장 LLM
- 기본 커넥터(Google Drive), 메신저 채널(Slack·Discord·Telegram) + 대화 로그
- 작업 기록부(감사 로그), 멤버 최대 10명, 이메일 지원

## 프로 — 월 ₩89,000 (연납 시 월 ₩71,000)
- 스타터 모든 기능 포함
- 모델 선택(내장/외부 LLM), 전체 MCP 커넥터 연결
- 검증 기준값·자가검증·이상 감지, 쓰기 전 미리보기·사람 승인 게이트
- 스케줄 자동 실행, 멤버 최대 50명, 우선 지원

## 비즈니스 — 월 ₩150,000 (연납 시 월 ₩120,000)
- 프로 모든 기능 포함
- 조직 단위 거버넌스, 역할별 권한 매트릭스
- 팀 협업(공유·공동 편집), 전담 온보딩

## 엔터프라이즈 — 영업팀 문의(사용량 기반 견적)
- 비즈니스 모든 기능 포함
- 설치형(On-premise)·프라이빗 클라우드
- SSO(SAML 2.0)·SCIM, 테넌트 격리(전용 스토리지·KMS·작업 기록부)
- 전담 고객 성공 매니저·SLA 보장, MCP 커스텀 연동
- 규제 산업 적합(금융·의료)

## 도입 참고
- 연납 시 약 20% 할인.
- 스타터→프로 상향의 주된 이유는 "사람 승인 게이트"와 "외부 모델 선택"이다.
- 규제·보안 요건(설치형·SSO·테넌트 격리)이 있으면 엔터프라이즈부터 검토한다.
