# Byr 제품 소개

## 한 줄 정의
Byr는 업무별 AI 에이전트를 만들어 반복 업무를 자동화하는 L3 Agentic AI 플랫폼이다. 사용자는 코드 없이 에이전트를 생성하고, 스킬과 외부 시스템(MCP 커넥터)을 연결해 실제 업무를 맡긴다.

## 핵심 차별점
- **사내 근거 기반**: 에이전트는 연결된 사내 문서·데이터에서 근거를 찾아 답하고, 모든 답변에 출처를 인용한다. 범용 챗봇과 달리 "우리 회사 자료" 기준으로 동작한다.
- **사람 승인 게이트**: 외부 발송·제출·쓰기 같은 고위험 작업은 사람이 미리보기로 확인하고 승인하기 전까지 실행되지 않는다. 초안은 새 버전으로 스테이징되며 기존 데이터를 덮어쓰지 않는다.
- **전 과정 감사 기록**: 누가 무엇을 언제 실행·승인했는지 작업 기록부(감사 로그)에 남는다. 규제 산업 대응에 필요하다.
- **메신저 네이티브**: Slack·Discord·Telegram 채널에 에이전트를 배치하면, 채널에서 바로 질문하고 결과를 승인한다.

## 주요 기능
- 업무별 에이전트 생성(직무 템플릿 제공: 재무·회계, 영업, CS, 인사, 개발 등)
- 스킬 조합(문서 요약, 데이터 대사, 리포트 생성, 제안서 초안 등)
- MCP 커넥터(Google Drive, Slack, 홈택스, DART, 사내 ERP 등) 연결
- 팀 에이전트 협업 흐름: 여러 에이전트가 핸드오프와 승인으로 하나의 업무를 처리
- 스케줄 자동 실행, 검증 기준값 대비 자가검증, 이상 감지

## 보안·배포
- 모델은 사내에서만 실행되며 데이터가 외부로 나가지 않는 옵션 제공(자체 LLM 우선).
- 클라우드(SaaS)와 설치형(On-premise·프라이빗 클라우드) 모두 지원.
- SSO(SAML 2.0)·SCIM, 테넌트 격리(전용 스토리지·KMS·작업 기록부)는 엔터프라이즈 등급.

## 적합 고객
개인·스타트업·중소기업부터, 금융·규제 산업의 대기업까지. 반복적인 문서·데이터 업무가 많고, AI 결과를 사람이 검증·승인하는 절차가 필요한 조직에 특히 적합하다.
